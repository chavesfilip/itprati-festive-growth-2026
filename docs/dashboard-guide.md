# Guia de utilização do dashboard

1. Entrar com conta individual; não partilhar credenciais.
2. Consultar Visão geral para metas e resultados.
3. Registar leads e actualizar cada etapa comercial.
4. Registar despesas no próprio dia, anexando comprovativo no sistema privado.
5. Criar tarefas com responsável e prazo.
6. Validar indicações apenas após pagamento e activação.
7. Rever visitas suspeitas antes de validar pontuação.
8. Exportar apenas dados necessários e guardar em local autorizado.

Os CSV deste repositório são modelos. Não devem armazenar dados pessoais.
