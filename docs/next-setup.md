# Preparação Next.js

O repositório foi preparado para Next.js 15 + React 19 + TypeScript, usando App Router.

Comandos: npm install, cp .env.example .env.local, npm run dev, npm run typecheck, npm run lint e npm run build.

A página inicial é uma estrutura visual inicial; os módulos de operação, autenticação e consultas reais ainda serão implementados. A migração SQL inicial cria tabelas com RLS activa, mas as políticas completas por função precisam de ser definidas antes de introduzir dados reais.
