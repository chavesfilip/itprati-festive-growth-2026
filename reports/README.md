# Relatórios

Guardar aqui relatórios agregados e sem dados pessoais:
- daily/: resumo diário de métricas.
- weekly/: análise semanal e decisões.
- monthly/: orçamento e resultados mensais.
- campaign-final/: avaliação final.

Não guardar exports de CRM, listas de leads, telefones, emails ou identificadores de clientes neste repositório. Usar apenas dados agregados e anonimizados.
