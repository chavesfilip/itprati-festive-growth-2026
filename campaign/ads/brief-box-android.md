# Brief de campanha — Box Android

## Objectivo
Apresentar a Box Android como dispositivo/solução, com características técnicas verificadas.

## Criativos
- Unboxing e instalação real.
- Demonstração de interface com aplicações autorizadas.
- Guia simples de utilização.

## Cuidados
Confirmar modelo, memória, conectividade, garantia, aplicações compatíveis e preço. Não prometer acesso gratuito a conteúdos pagos ou não licenciados.
