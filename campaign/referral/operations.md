# Operação diária — Indica 4

1. Criar código único para cliente elegível.
2. Registar cada indicação no CRM/dashboard privado.
3. Verificar se é novo cliente e se não existe indicação anterior.
4. Confirmar pagamento com o sistema financeiro.
5. Confirmar activação com a equipa técnica.
6. Marcar como válida apenas depois das duas confirmações.
7. Quando atingir quatro indicações válidas, abrir tarefa de validação.
8. Responsável autorizado aprova e regista a recompensa aplicada.
9. Notificar o cliente pelos canais autorizados.
10. Rever semanalmente duplicados, estornos e reclamações.

Campos mínimos no sistema privado: ID do indicador, código, ID do referido, serviço, data de registo, pagamento confirmado, activação confirmada, estado, validador, data de validação, recompensa e data de aplicação.
